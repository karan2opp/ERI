# Features to build in the future

These are decided but not started. The shorter-term plan, the map-loading plan and the hosting checklist are in [TODO.md](TODO.md).

## Tree pages and the public site

### Tree share link and printable QR tag
A page for a single tree, so one tree can be shared or found from the tree itself.
- A link per tree (for example `/?tree=<id>`), like drives already have
- A printable QR tag that opens that tree's page, for fixing to the trunk

### Public home page for visitors
- Live totals (for example "2,431 trees planted")
- Species counts
- A leaderboard

### Tree life events
- Mark a tree as dead or replaced
- A growth photo timeline for each tree

## Reports and moderation
- Report a wrong tree or a bad photo
- Ban a bad user
- An admin activity log (who did what, and when)

## Drives

### Drive results (wait for the first real drives)
Store what a drive achieved. We wait until real clean-up and planting drives have run, to see what you actually want to record.
- Clean-up drives: kilograms collected, bags filled, before and after photos
- Plantation drives: number of trees planted
